Markus Spann

Developer from Munich, Germany. Open source, mostly Java.

  • UCanAccess and Jackcess, pure Java libraries for reading and writing Microsoft Access databases (.mdb, .accdb). UCanAccess is a JDBC driver built on top of Jackcess, jackcess-encrypt adds support for encrypted files. UCanAccess site
  • iban-commons, an allocation-free IBAN and BIC toolkit for Java 8+.
  • figlet, a Java library (figlet4j) and Maven plugin that renders text as ASCII art banners, without a native figlet binary. Font gallery
